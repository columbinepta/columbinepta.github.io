# columbinepta.org

The public website of the Columbine Elementary PTA (Boulder, BVSD), served by
GitHub Pages.

These files are a static copy of the old Weebly site, taken on 2026-10-12 so
the site stays up after Weebly shuts down on 2026-12-26. Do not edit them by
hand. They are generated by `tools/build_pages.py` in the private
`columbinepta/website` repository, which also holds the raw copy and the notes
on the domain move.

What does not work on a static host:

- The Weebly store checkout for the grocery cards. Those move to Givebacks.
- The Weebly contact forms. The build replaces them with the PTA email address.
